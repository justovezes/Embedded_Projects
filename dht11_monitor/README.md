
# DHT11 Monitor with SDD1306
DHT11 readings with SDD1306 as display.

Credits for:
DHT11 driver, at https://github.com/esp-idf-lib/dht ("dht.h")

SDD1306 driver, at https://github.com/nopnop2002/esp-idf-ssd1306 ("sdd1306.h")

Umidity/Temp is read with DHT11, then output to SDD1306, and refreshed every 3 seconds.
No AI was used in the code.
